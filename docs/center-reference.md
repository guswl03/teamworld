# 센터 맵 및 멘토 안내 자료

이 프로젝트의 센터는 판교 정보보호 교육센터를 모티브로 한 **비공식 가상 공간**입니다. 실제 건물 4층의 평면도, 실제 좌석 배치 또는 실제 멘토 근무 위치를 재현하지 않습니다.

## 공개 위치 자료 (2026-09-06 확인)

- [BoB 공식 사이트](https://www.bobedu.kr/): 판교사무소 주소 — 경기도 성남시 수정구 대왕판교로 815, 기업지원허브 혁신기술존 4층.
- [KISA 판교사무소 위치 안내](https://www.kisa.or.kr/60703): 동일 건물의 정보보호 클러스터 4·5층 안내.
- [같은 기업지원허브 내 메타버스허브 위치 안내 PDF](https://reserve.dccenter.kr/img/ncia_edm_img/2024/metaversehub_MEC_e-Brochure.pdf): 건물 접근 위치 참고용이며 BoB 실내 도면이 아님.

실내 설계는 실제 도면이 아니라 입구·안내 데스크, 중앙 라운지, 강의·실습실, 프로젝트룸, 멘토링 공간을 연결한 게임용 구성입니다. 벽·가구는 외부 사진을 복제하지 않은 자체 Phaser 그래픽입니다.

## 멘토 데이터

사용자가 제공한 멘토 명단 화면과 '트랙교육 커리큘럼 — 시스템 계통 + 서비스 계통' 표를 참고했습니다. 개인 프로필 사진은 복사하거나 캐릭터 외형 추정에 사용하지 않았습니다. 게임 캐릭터는 가상의 IT 아바타입니다.

전상현(시스템 프로그래밍), 강대명(파일시스템), 김관영(Git/GitHub·차량보안·Recon), 김주생(가상메모리·보안 특허), 김태홍(생성형 AI 보안), 남성엽(오펜시브 시큐리티), 문재현(AI 이해·적용), 박수현(생성형 AI 웹서비스), 이경문(Network Protocol), 장상근(바이브 엔지니어링), 한현상(클라우드·AI 보안)의 주제를 표에서 확인했습니다. 양혁재는 명단에만 있어 담당 주제를 미확인으로 표시합니다.

NPC 내용은 커리큘럼을 요약한 게임 안내로 실제 멘토의 인용 발언, 공식 강의 자료, 실시간 상담 또는 전문성 평가가 아닙니다. 원본 채팅 화면과 커리큘럼 스크린샷은 저장소에 포함하지 않았습니다.

## 호환성

기존 프로필 avatar ID와 팀 ID, 채팅 transport, 탐험 기록 v1 키를 유지합니다. 구 마을 명소의 내부 ID는 저장 기록 호환성을 위해 보존하고 표시 이름/좌표만 센터에 맞춥니다. 전체 지도 이동은 기존과 같이 데스크톱에서 지원하며 작은 모바일 화면에서는 메뉴와 채팅을 사용합니다.
