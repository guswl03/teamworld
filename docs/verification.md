# TeamWorld v0.1 검증 기록

## 로컬 검증

- `pnpm test`: 16개 통과. 이동/충돌/프로필, BroadcastChannel 두 클라이언트, PGlite에서 실제 SQL 마이그레이션 및 RLS 정책을 검증했습니다.
- `pnpm typecheck`: 통과.
- `pnpm build`: 모든 페이지의 프로덕션 빌드 통과.
- 데스크톱 1280×720: 랜딩, 온보딩, 5개 길드/중앙 광장, 캔버스 렌더링, 프로필/상태 UI 표시 확인. 문서 너비와 화면 너비 일치.
- 두 브라우저 탭: ‘모험가 한결’과 ‘별빛 지우’를 서로 다른 팀으로 만들고 양쪽에서 2명 접속 확인. 중앙 광장 이동 후 키보드 입력으로 x=800 → 809 이동 확인. 상대 캐릭터와 ‘집중 중/회의 중’ 상태 수신 확인.
- 설정 이동 시 상대 목록에서 사라지고 접속 인원이 1명으로 줄어드는 것을 확인.
- 설정에서 ‘지우의 모험’으로 이름과 캐릭터를 변경하고 재입장/새로고침 후 복원 확인.
- 모바일 390×844: 동료 목록/상태 선택 표시, 불필요한 게임 캔버스 0개, 문서 너비 390px, 실행 오류/경고 없음.
