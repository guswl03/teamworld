# TeamWorld 검증 기록

## RPG UI 테마 — 2026-09-05

- 월드의 상단 명패, 위치 표시, 퀘스트 카드, 하단 메뉴, 채팅·설정 창과 NPC 안내 대화를 나무/양피지/숲색으로 통일했습니다. 랜딩 및 별도 온보딩 화면은 변경하지 않습니다.
- 장식용 메뉴 아이콘 6개는 직접 작성한 16px 격자 SVG이며 CSS에 포함됩니다. 추가 다운로드·폰트·의존성은 없습니다. 기존 버튼 이름과 기능은 유지합니다.
- 변경 전 브라우저에서 상단/하단/작업 창의 둥근 모서리 및 흐림 효과를 확인했고, 변경 후 세 요소 모두 `border-radius: 0px`, `backdrop-filter: none` 확인. 안내 대화의 배경 흐림도 제거됐습니다.
- 실제 화면에서 월드 HUD, 채팅, 프로필 선택/입력, 탐험 안내를 확인했습니다. 안내 → Esc → Esc 후 CANVAS 포커스 복귀 유지. 좁은 화면의 실제 DOM 너비 487px과 문서 너비가 같고, 설정 창과 메뉴가 화면 안에 들어갑니다. 임시 화면 크기는 확인 후 복원했습니다.
- 조작 로직은 변경하지 않았습니다. 스타일 변경의 검증은 브라우저 시각 점검과 기존 회귀 테스트를 사용합니다.

## 월드 중심 작업 공간 — 2026-09-05

- 고정 좌우 사이드바 대신 전체 화면 월드와 6개 하단 메뉴를 적용했습니다. 채팅·동료·퀘스트·배낭·길드·프로필 설정은 월드 위 창에서 동작합니다.
- 입력 상태 회귀 테스트 4개를 추가해 총 29개 통과. 타입 검사, 소스/테스트 Prettier 검사, 프로덕션 빌드 통과.
- 실제 DOM 기준 데스크톱 1600×1000에서 캔버스가 화면 전체를 채웁니다. 새로고침 후 포커스가 CANVAS이며, 지도 클릭 없이 D 입력으로 좌표 310,410 → 313,410 이동을 확인했습니다.
- 작업 창에서 이동 키를 반복해도 좌표가 유지됩니다. 채팅 초안은 닫기/다른 창 전환 후 유지되며, 전송한 메시지는 창을 다시 열어도 표시됩니다.
- 월드 안 설정 저장 후 URL, 위치 및 게임 화면 유지 확인. 퀘스트 → 탐험 안내 → Esc → Esc 순서에서 포커스가 BODY에 남던 문제를 재현하고 수정했습니다. 수정 후 CANVAS 복귀 및 추가 클릭 없는 이동을 확인했습니다.
- 배낭의 기존 보상/모자 착용 상태 표시, 길드 메뉴의 중앙 광장 이동 확인.
- 모바일 테스트 설정 390×844, 브라우저 확대/축소를 반영한 실제 DOM 488×1055: 가로 넘침 없음, 캔버스 0개, 작업 창이 화면 안에 표시되며 채팅 전송 성공. 임시 크기 설정은 검증 후 해제했습니다.
- 독립 코드 리뷰에서 숨겨진 채팅의 자동 스크롤 및 늦은 설정 저장 응답이 다른 패널을 닫는 경우를 찾아 보완했습니다. 느린 호스팅 저장 응답과 대량 수신 중 스크롤은 코드 검토로 확인했으며 실서버 지연 시나리오는 미검증입니다.
- 새 의존성, 마이그레이션, 커밋, 푸시, 배포 없음. 실제 OS IME 조합 및 호스팅 Supabase 연결 제한은 아래 기록과 같습니다.

## v0.2 개발 버전 — 2026-09-05

- `pnpm test`: 25개 통과. 기존 이동/권한 테스트에 퀘스트 순서·거리·중복 보상·저장값 검증, 채팅 길이·빈도·세션·세계·중복 검증, 실제 두 BroadcastChannel 클라이언트 채팅, Tiled/PNG 호환성과 애니메이션 프레임 검사를 추가했습니다.
- `pnpm typecheck`, `pnpm build`: 통과. 변경 파일에 대한 Prettier 검사 수행. 원본 명세 문서의 기존 포맷은 보존합니다.
- 현재 작업 사본의 개발 서버 `http://127.0.0.1:3102/world`에서 확인했습니다. `3101`은 이전 미리보기입니다.
- 데스크톱 1440×1000: CC0 지형/건물/나무/양과 캐릭터 표시, 길드 이동, WASD, 루미의 E 대화 확인. 문서 너비 1440px, 검사 시 브라우저 오류/경고 로그 없음.
- 새 그래픽으로 정원 → 시장 → 연못을 방문해 3/3 달성, 상자 개봉, 루미에게 보고, 배낭의 모자 착용 확인. 새로고침 후 완료/착용 상태 복원 확인. 이름표는 모자와 겹치지 않도록 위로 배치했습니다.
- ‘마을 탐험가’와 ‘별빛 친구’ 두 탭 사이 양방향 전송. `<b>반가워요</b>`가 태그가 아닌 글자로 표시됨을 확인. 채팅 입력의 ArrowLeft/Enter 이후 좌표가 `748, 640`으로 유지됐습니다. 새로고침 후 채팅 기록이 비워짐도 확인했습니다.
- 모바일 390×844: 캔버스 0개, 문서 너비 375px(스크롤바 제외, 가로 넘침 없음), 채팅 입력/전송 성공 및 PC 탭 수신 확인. 테스트 크기 설정은 종료 후 해제했습니다.
- 소재는 공식 `TS_old version_CC0 Licensed` 다운로드에서 PNG 18개만 선별했습니다. 원본 경로·해시·라이선스 근거는 `public/assets/tiny-swords/PROVENANCE.md`에 있습니다. 유료 구매/의존성 추가/마이그레이션/커밋/푸시/배포 없음.

### 남은 검증 및 제한

- 한국어 입력/전송은 확인했지만 실제 운영체제 IME 조합 중 Enter는 자동화 환경에서 재현하지 못했습니다. 조합 이벤트와 keyCode 229 방어가 구현되어 있습니다.
- 독립 코드 리뷰 도구는 사용량 제한으로 완료하지 못했습니다. 자동 테스트와 직접 브라우저 검증 결과만 보고합니다.
- 모자/탐험은 로컬 저장이며 동료에게 동기화되지 않습니다. Tiled 파일은 지형만 담당하고, 충돌과 퀘스트 위치는 코드에서 관리합니다.
- Supabase 실제 계정/서버 연결 검증은 아래와 같이 미완료입니다.
