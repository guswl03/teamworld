## 남은 범위

- 사용자 요청으로 **멘토 12명 신규 개별 이미지 제작은 보류**했습니다. 현재는 기존 IT 아틀라스의 임시 변형 캐릭터를 사용합니다. 이 단계에서 새 멘토 이미지를 생성하지 않았습니다.
- 센터는 실제 평면도 복제가 아니며, 멘토 체크리스트는 안내창 내 임시 상태입니다. 실시간 멘토 상담, 실제 업무 퀘스트 연동, 모바일 지도 이동은 제공하지 않습니다.
- 실제 서로 다른 PC의 호스팅 로그인/Realtime 연결은 검증하지 않았습니다. 기존 로컬 transport/DB 정책 테스트는 전체 테스트에 포함됩니다.
- 커밋·푸시·배포를 수행하지 않았습니다.

## 2026-09-06 맵과 UI 영역 분리

- 수정 전 1048×888 화면에서 DOM 경계 검사로 헤더, 위치, 퀘스트, 하단 메뉴가 맵과 겹치는 것을 재현했다.
- 상단 정보 / 중앙 맵·작업창 / 안내줄 / 하단 메뉴를 실제 그리드 영역으로 분리했다. 작업창은 계속 마운트하며 캔버스는 기존 ResizeObserver로 크기를 조절한다.
- 같은 검사에서 기본 화면·설정·채팅과 맵의 겹침이 0건임을 확인했다. 1048×888에서는 좌우, 780×950에서는 상하, 625×600에서는 좌우 배치가 적용되었다.
- 390×844 모바일에서 헤더·설정·메뉴가 화면 안에 들어오고 가로 넘침이 없는 것을 확인했다. 모바일 월드 이동 미지원 정책은 유지한다.
- Enter로 채팅 입력에 포커스, Esc로 캔버스 복귀 및 위치 유지 확인. 37개 테스트, 타입 검사, 프로덕션 빌드 통과.
- 독립 리뷰에서 발견한 모바일 재연결 버튼 숨김을 수정했다. 실제 연결 장애 재현은 수행하지 않았다.
- 새 이미지 생성, 의존성 추가, 커밋·푸시는 하지 않았다.
- 패널 토글 뒤 캔버스가 이전 크기에 머무는 회귀도 재현했다. Phaser RESIZE 모드의 부모 크기를 갱신하도록 수정하고 새로고침 후 채팅 열기(569px)·닫기(1012px)에서 캔버스와 부모 영역의 크기가 일치함을 확인했다.
